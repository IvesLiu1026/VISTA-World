# Contributing

VISTA World uses small, evidence-backed pull requests.

1. Start from current `main` in a short-lived branch/worktree.
2. State the issue/finding, acceptance criterion, and owned paths.
3. Add or update focused regression tests.
4. Run the relevant offline checks and `git diff --check`.
5. Open a draft pull request with commands and results.

Do not include credentials, external asset payloads, Unreal/Blender binaries, runtime
logs, generated evidence, canonical datasets, or unlicensed content. Dependency,
workflow, policy, runtime, networking, and schema-compatibility changes require human
review even when generated by automation.
