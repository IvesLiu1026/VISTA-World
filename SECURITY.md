# Security Policy

Please do not open a public issue containing credentials, private URLs, access tokens,
dataset evidence, or exploitable details. Use GitHub's private security advisory flow
for this repository once enabled, or contact the repository owner privately.

The Daily Maintainer is fail-closed: its AI patcher must not possess GitHub write
credentials, and its publisher must not execute repository code while holding a write
token. A suspected boundary escape disables unattended publication until reviewed.
