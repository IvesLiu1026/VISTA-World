# Villa R1：依照生成設計圖製作與驗收

2026-09-10。目標是可近看、可走動、可操作的住宅。設計圖決定方向；品質以 Unreal 實機與實際操作判定。目前仍未達到完整 GTA 品質。

## 四項實作的驗收邊界

1. **人物。**沿用可用的 MakeHuman CC0 骨架與皮膚來源，增加眼睛／角膜、衣物表面與綁定髮絲；owner body 和 world body 同步。這仍是改良的展示角色，沒有完整 facial rig、布料求解或 AAA 頭髮系統。
2. **動作。**CMU 三段步行來源轉為 203 個動作樣本，修正 T-pose／A-pose 肢體方向，依速度、腳步相位與姿勢連續性選片，再接現有 IK。不是 Epic PoseSearch 的大型 Motion Matching 資料庫。第一人稱空手、低頭身體、切換視角和拿放均保留原生檢查。
3. **空間與物品。**兩層住宅、60 組拆分幾何、實際材質槽、照片 PBR、薄壁杯壺與動態碰撞；水槽開口同時穿過檯面與櫃體。R5 原始專案、入口和執行中的 demo 保留，新版另有入口。
4. **液體與操作。**原生角色可走近、抓壺、倒入杯中、放回並控制龍頭。液體是混合模型：守恆水量帳本、受重力方向約束的容器液面、細水柱的彈道表面，以及 Niagara 3D FLIP 的粗網格流體。關掉來源後已流出的部分繼續運動；FLIP 粒子數不是水量量測。

## 實機證據

每次執行記錄實際地圖和外掛 SHA-256、NVIDIA GPU、1920 × 1080 畫面、拿放計數、水量殘差及上樓結果。快照在骨骼更新完成後讀取，手腕到目標的誤差不能被當成手指皮膚接觸或力閉合的證明。

數值檢查通過後仍需看畫面：材質棋盤格、被櫃體堵住的水槽、看不見的水流，都不能靠正常 exit code 或正粒子數判定通過。最終實測與圖像見同目錄 `implementation-manifest.json`。Frame time 包含自動截圖，尚未達成穩定 1080p 30 fps。

## 研究銜接

[VISTA](https://arxiv.org/html/2605.10579v2) 與 [EgoArgus](https://arxiv.org/html/2608.25561v1) 的關係已記錄在私人研究筆記。下一步研究是在相同世界起點下比較沉默、及時提醒及延遲提醒，量測人物反應和後續損失。新的別墅目前提供操作基礎；可還原世界、自然語言動作規劃與完整助理閉環仍需接入。

舊 Home 的六空間事件和新別墅廚房操作是不同的驗收範圍。不能把 R5 全事件通過直接當作所有事件已移植到 Villa，也不能把生成圖的寫實程度當作即時渲染成果。
