# 生成參考圖的一致性檢查

2026-09-06；依本次工具實際回傳的圖片目視檢查。這是設計參考審閱，並非 Blender／UE 實機驗收。

最終選用 9 張參考板，另保留 1 張被替換的衛浴初版。所有實際回傳檔案均為 **1672 × 941 px**；提示詞雖請求 3840 × 2160，工具並未回傳該解析度，因此不能稱為 4K。每個面板的有效像素更少，只適合外觀與構造參考，不是正式貼圖來源。

| 圖片 | 可採用的外觀參考 | 幾何／功能上需要解決的事項 |
|---|---|---|
| 玄關／走廊 | 木地板與磨石子轉接、鞋櫃、門框與生活用品的質感 | 畫面感受明顯比來源的 3m 名義寬度窄。用數值建模並重新選相機；五個室內門位置依平面契約固定。 |
| 客廳 | 布沙發縫線與壓痕、木桌、自然窗光 | 圖片不能證明每個相機下門與家具都符合既定座標；家具尺寸與門所在牆面需用同一 Blender 場景確認。 |
| 廚房／餐區 | 灰綠櫃體、石材檯面、磁磚接縫、金屬水槽 | 兩個廣角面板視角差異偏小。櫃體模組分割、把手和水龍頭細節不可直接逐面照抄；鍋／杯／冰箱改以各自物件規格為準。 |
| 臥室 | 棉布摺痕、床架、床邊燈與木作 | 衣櫃在不同面板中相對床的方位有漂移，床頭櫃數量也不完全一致。定稿採一份數值配置再重新渲染。 |
| 書房 | 木桌厚度、日常辦公物件、椅子的表面細節 | 梯子與書櫃的相對位置需要統一；黑色椅面部分視圖像皮面而不是指定布面。建模時選定單一材質與椅架形狀。 |
| 衛浴／洗衣 | 磁磚、玻璃、浴缸與水龍頭安裝細節 | 初版缺馬桶，已做局部修訂加入一致的馬桶位置。新模型仍需確認馬桶與浴缸間距、洗衣機門開啟、乾濕區和動線。 |
| 不鏽鋼鍋 | 雙側把手、鉚釘、包底、獨立鍋蓋和內壁 | 視圖未經相機校準；把手／鉚釘位置、實際壁厚及鍋蓋配合間隙以 asset-briefs.json 和 Blender 實體幾何確定。 |
| 陶瓷杯 | 釉面、杯口、內壁、杯把接點與無釉足圈 | 預定的右側視圖沒有完整呈現把手；不能依該面板推定把手背面形狀或孔洞。 |
| 對開冰箱 | 櫃體、背板、獨立門片、內膽、層板和門邊置物架 | 頂視圖仍帶透視。門片左右寬度、把手形狀、鉸鏈位置和開門角度必須以獨立零件建模並檢查。 |

## 下一步應固定的內容

1. 建立一份數值化的廚房家具布局，尤其是檯面模組、冰箱開門空間、人物接近路徑和放置檯面。
2. 用同一個 Blender 場景產生真正一致的多角度畫面；需要追加圖片時，以這些固定幾何的 render 作為參考。
3. 分開建立物件形狀、PBR 材質、碰撞、pivot、握持點與動作錨點。
4. 在一般曝光、人眼高度與近距離檢查質感；再在 UE 驗證行走、開門、拿取、放置。

## 工具與來源

使用內建 `image_gen` 工具；沒有呼叫 Higgsfield 或 OpenRouter，也沒有使用使用者的 API key。使用者指定的模型為 GPT Image 2，但內建工具回應沒有包含底層模型 ID，所以紀錄為 requested model，沒有把它當成已獨立驗證的模型版本。圖片、提示詞、修訂來源和雜湊均在 manifest 中。
