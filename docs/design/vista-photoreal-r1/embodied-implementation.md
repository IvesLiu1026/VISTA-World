# 全身角色與杯子互動 R1

2026-09-07。在已完成的六房住宅加入同一個全身角色、第一／第三人稱切換，以及杯子的伸手、握住、拿起、持物行走、放置、鬆手掉落與重新拿取。此版在 `codex/vista-embodied-interaction-r1` 開發，沿用住宅資產，使用獨立 UE 專案副本。

最終 `build-v` 已接入 Sunshine，遊戲與輸入服務正常運作，角色重置在餐桌旁。舊版住宅及其他五個 Sunshine 入口保留。

## 操作

Sunshine 應用程式：**VISTA Photoreal Home**。進入後在餐桌旁，杯子位於桌緣。先看向杯子按 `E`，拿起後看向附近桌面再按 `E` 放置；畫面下方會提示目前可執行的動作。

| 按鍵 | 動作 |
| --- | --- |
| WASD、滑鼠 | 走動、轉向；第一人稱低頭可見衣服、雙腿與鞋子 |
| Tab | 第一／第三人稱切換，保留目前位置與抓取進度 |
| E／滑鼠左鍵 | 伸手拿杯；持杯時放到瞄準的近處水平支撐面 |
| G | 取消伸手，或鬆手讓杯子自由掉落 |
| R | 重置杯子並回到餐桌檢視位置 |
| 0 | 回到餐桌檢視位置 |
| 1–6、V | 切換房間、查看房間另一角度 |
| Esc | 釋放／重新捕捉游標 |

杯子若掉在地上，走近並看向它再按 `E`。桌面拿取的最遠候選距離是 86 cm；地面物件需接近至 46 cm 內，且仍須通過手臂可達與接觸檢查。看得到並不保證手伸得到。放置需有距身體 60 cm 內的完整水平支撐，杯底不能懸空或與家具重疊。

## 實作與素材

角色沿用本機已有的 MakeHuman CC0 來源，53 根骨骼包含雙手各五指三節。Blender 腳本輸出完整世界身體與去除頭部內側的第一人稱身體，兩者共用同一份骨架姿勢。第三人稱相機帶碰撞回縮；第一人稱依角色實際眼位校正，低頭時加入上半身前傾，鏡頭平移平滑處理，但不直接繼承全部頭部旋轉。

輸出前先烘焙 MakeHuman 正在使用的身形 shape-key 混合，保留皮膚、骨架與衣物的配合。重新匯入 GLB 的 4,801 個皮膚頂點與原始已塑形網格比對，最大最近頂點誤差為 1.32 mm，平均約 0.005 mm。這項檢查解決來源身形在輸出時遺失所造成的手指、肩膀與衣物錯位；不代表人體外觀已達掃描或電影級品質。

走路使用程序化步態、腳掌支撐點、腳跟抬起、骨盆高度調整與雙骨 IK。急停時重新安排正在落地的腳，腳底以多點取樣跨過地板接縫；持杯時使用後退／側移，身體依視線平緩轉向。手部使用 Blender 編修的張手／杯身上緣握姿，配合手臂 IK 和物件局部握點。骨骼接觸量測放在物理與姿勢運算完成之後，避免把前一幀的手或腳誤當成這一幀的接觸。

杯子重用原住宅陶瓷杯幾何，改為杯底中心局部原點，杯身半徑 4.3 cm、高 9.6 cm、質量 0.32 kg。碰撞由 17 個凸形體和 5 個杯把膠囊組成，保留杯把孔隙。新副本將杯子從餐桌中央移至桌緣 `(334, 317, 76.8) cm`，方便實際站立拿取；舊住宅專案保持原樣。

伸手先確認距離、視線與手的接近路徑；手腕握點位置誤差小於 1 cm、方向誤差小於 10° 後才握住。杯子全程保持動態剛體，由 Physics Handle 持住。貼牆時限制並沿牆面調整持物目標，手跟隨物理杯子的實際位置。放置確認支撐、接觸與速度後才張開手指、解除約束。

這是手工抓姿、程序化 IK 與物理約束的組合。沒有新增生成圖片／影片、付費 API、MoCap 下載、模型推論或訓練；也沒有宣稱重現 GRAB、Omnigrasp 或 InterMimic。技能與論文核查保留於 [技術調查](embodied-interaction-research.md)。

編譯檢查涵蓋 Linux UnrealEditor、UnrealGame Development 與 Shipping。既有公開資料契約／編譯器的 28 項測試通過，記錄於 `logs/baseline-tests.log`。執行檢查使用實際 X11 按鍵與原生 UE F8 截圖；控制台指令僅定位驗證情境或讀取狀態。每張截圖保存同一幀完成姿勢運算後的狀態與 SHA-256。

最終版通過 20 次交替視角的連續拿放、五處門口在兩種視角下來回共 20 次通行、70／85／100 cm 支撐高度與三種杯把朝向，以及取消、遮擋拒絕、中途換視角、掉落再拿、持杯貼牆、鏡頭回縮與離牆恢復。Sunshine 使用的顯示 `:119` 另完成拿取、持杯切換、放置、低頭與重置複查；遠端用戶端的實際串流觀感由使用者進入檢視。

最終步態量測涵蓋 226 幀、310 個支撐腳樣本，走動跨度 484.29 cm。骨骼支撐點最大偏差與同次支撐期間的滑移皆小於 0.01 cm，支撐腳趾骨的最低世界高度為 1.01 cm，位於地面上方；這是遊戲骨骼幾何量測，沒有把它當成逐指／逐腳接觸力的精度。

1920 × 1080、100% 內部解析度、TSR、30 fps 上限，在 GPU 0 與既有 R23／R6 展示共用的條件下，步行的幀時間中位數是 **51.45 ms（約 19.4 fps）**，p95 為 72.12 ms。實錄檔案以 30 fps 擷取；這不代表遊戲全程穩定 30 fps。

第一／第三人稱實錄各約 15 秒，包含伸手、拿起、後退／走回、放置與鬆手。已檢視實錄的接觸、持物行走與放置畫面。

## 範圍與後續品質

目前精細操作對象是杯子。冰箱既有 `F` 開關仍可用，但還沒有手貼把手的操作；雙手端鍋也尚未接入。角色的皮膚、指甲、衣物與步態仍可繼續提升，現有動作不是真人 MoCap。手腕接觸數字不能代替逐指碰撞或摩擦力驗證：本版手指依已編修的握姿彎曲，物件穩定由物理約束維持。

此分支是本機住宅互動檢視，尚未整合回原有任務執行器、研究評測或正式環境。R23／R6 展示、舊住宅 `home-r1-20260906a/project-g`、來源角色與 Sunshine 認證均保留。
