# VISTA Event Projection Ledger

This public baseline contains seven event **projections**: small, contract-shaped scenario records
derived from VISTA sample IDs that were reviewed in the source research workspace. The public files
are validated by the repository schemas and regression tests. Their `vista://` references are stable
internal provenance identifiers, not public download URLs.

What an external reader can verify here:

- the exact event JSON bytes and SHA-256 digests below;
- conformance to the public event schema;
- deterministic inclusion in the playable-home compiler and tests.

What this repository does not currently publish:

- the underlying VISTA videos, annotations, dialogue, or private evidence ledger;
- enough public evidence to independently repeat the source research review;
- any redistribution or usage right for external dataset media or referenced 3D assets.

Accordingly, `"verification": "verified"` in an event record means “internally reviewed before
projection,” not “independently reproducible from public evidence.”
